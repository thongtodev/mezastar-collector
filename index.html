Cài đặt APK

Cách cài app không qua CH Play

App hiện được phát hành dạng APK để dùng thử nội bộ. Khi tải file APK, Android có thể hỏi quyền cài ứng dụng từ nguồn ngoài.

  1. Tải APKBấm nút tải ở website hoặc GitHub Releases.
  2. Mở file APKChọn file vừa tải trong trình quản lý tệp/tải xuống.
  3. Cho phép cài đặtBật “Cài ứng dụng không rõ nguồn gốc” nếu Android yêu cầu.
  4. Đăng nhập và dùngĐăng nhập để đồng bộ tag, trade và Trainer Ticket.
