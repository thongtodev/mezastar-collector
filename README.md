# Mezastar Collector Landing Page

Landing page tĩnh để đăng lên GitHub Pages và giới thiệu app Android **Mezastar Collector**.

## Cách dùng

1. Upload toàn bộ file trong thư mục này lên GitHub repo.
2. Vào `Settings > Pages`.
3. Chọn `Deploy from branch` → `main` → `/root`.
4. Trong `index.html`, đổi `YOUR_USERNAME/mezastar-collector` thành repo thật của bạn.
5. Upload APK vào GitHub Releases và để người dùng tải từ nút trên website.

## File ảnh

Các ảnh trong `assets/` là ảnh chụp giao diện thực tế của app.

## Lưu ý

Website có phong cách lấy cảm hứng từ game/app sưu tầm sinh vật, nhưng không dùng logo hoặc tài sản chính thức của Pokémon/Takara Tomy. Nên giữ disclaimer ở cuối trang khi public.
